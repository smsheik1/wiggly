# Character sheet recipe — scoped layout reference

The host agent reads the actual selected character image and composes a prompt for that specific identity. Preserve face, age, hairline, eye color, body proportions, clothing, accessories and distinguishing traits from the approved design. Describe a cinematic stylized 3D character with coherent materials and expressive readable acting; do not replace their features with a generic face.

Use a clean neutral studio background, consistent neutral lighting and spacing. Top row: four matching full-body neutral poses, front, three-quarter, profile and back. Keep the body, shoes, hands and hairstyle visible without cropping. Below: eight matching head/shoulder expression portraits in two rows of four. Name each expression explicitly in the authored prompt. Do not turn an expression change into a new age, hairstyle or outfit. The agent must establish the intended eight expression labels in context; angry versus determined is still an open design choice.

Send the selected design image with this prompt to the image provider. A prompt that mentions an unseen sheet or character name is insufficient grounding. Review the resulting sheet for exact view/expression count, completeness, identity, anatomy, consistent outfit and recognizable acting. User approval follows the agent pass.

This concise project-authored recipe captures the layout discussed with the user. The tutorial-derived Dan Kieft files are reference material, not an instruction to execute the entire tutorial or a packaged copyrighted prompt pack. User-provided Mia example images are illustrative and are not shipped as production identity assets.
