# Wiggly Discovery Research

This folder is the living evidence base for Wiggly Discovery.

## Product Lens

Wiggly Discovery is for someone who needs an ad format to use. Finished ads lead the experience. The reusable Format, its creator, and its proof sit behind the result.

North star:

> I can make this. Wiggly has already turned it into an exact science.

Core loop:

`See an amazing ad -> understand the repeatable Format -> use it with an agent -> publish a result -> credit the creator`

## Research Method

1. Breadth scan across creator marketplaces, visual galleries, model registries, workflow libraries, and agent marketplaces.
2. Deep dives into the strongest product and interaction patterns.
3. Component research for feeds, detail pages, search, trust, agent handoff, reuse, and lineage.
4. Prototype review against the accumulated evidence.

Each round adds screenshots, findings, rejected patterns, and changes in confidence. Later rounds do not erase earlier findings.

## Guardrails

- Borrow useful behavior, not unrelated visual styles.
- Keep one coherent Wiggly design language.
- Design for ad seekers first and Format creators second.
- Keep public publishing curated during the MVP.
- Do not add payments, direct messages, followers, comments, ratings, or an algorithmic feed in the MVP.
- Preserve `/format-lab` as technical proof. Consumer discovery belongs on a separate public surface.
