## Phase 1 Focus: Superpower #1 — Dynamic Trend & Topic Scraper

### 1. The Core Problem
Right now, whenever a creator or agent boots up a Wiggly format repo, the first prompt is:
> *"What should this video be about?"*

This forces the user to switch tabs, spend 20 minutes browsing YouTube, Reddit, or Twitter, and come up with ideas. Most users experience blank-canvas fatigue and end up typing generic concepts (e.g. *"make a video about Batman fighting Joker"*), which produces low-retention, generic content.

### 2. The Superpower Shift
The agent transforms from a **passive order-taker** into an **autonomous viral scout and executive producer**.

When initialized, the agent probes real-time cultural momentum and responds:
> *"I scanned real-time YouTube search velocity and community debates. Here are 3 explosive topics trending right now for this format:*
> 1. **The Tactical Debate:** *Could Batman survive without REM sleep? (84k searches/mo, high controversy)*
> 2. **The Financial Feasibility:** *How much does Batman spend crashing Batwings every year? (Wayne Aerospace subsidy)*
> 3. **The Legal Catch-22:** *Why executes Joker would trigger New Jersey penal code mistrials across 40 inmates.*
>
> *Reply 1, 2, or 3 to proceed, or drop your own topic."*

### 3. Data Ingestion Channels (Zero-Cost, High-Signal)
- **Live YouTube Search Autocomplete (`ds=yt`):**
  Direct real-time reflection of millions of active viewer searches with zero API keys or rate limits (`suggestqueries.google.com`).
- **Google Daily Trends RSS:**
  Real-time breakout cultural phenomena.
- **HackerNews Algolia REST API:**
  High-signal developer & technology A-vs-B debates for explainer formats.
- **Serper / Web Scraping:**
  Deep-dive into Reddit debates (e.g. `r/whowouldwin`, `r/Batman`, `r/ProgrammerHumor`) where fans argue nuanced points.

### 4. Format-Specific Ingestion Blueprints
- **`character-gameplay-conversations`:** Forensic lore paradoxes, tactical Batman/Robin debates, superhero physics.
- **`mugsy-explains-v1`:** Software engineering holy wars (e.g. Docker vs Podman, Bun vs Node, Postgres vs SQLite).
- **`talking-fish-news-v1`:** Bizarre scientific discoveries, astronomical events, and strange real-world news.
- **`bikini-bottom-dance-off-v1`:** Viral audio tracks, trending Billboard choreography, meme soundbites.
- **`animal-conversations`:** Trending funny animal videos on TikTok/Instagram.
